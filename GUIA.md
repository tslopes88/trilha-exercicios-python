# Guia do Projeto: Trilha de Exercícios de Python

Este guia acompanha o arquivo `projeto_exercicios_python.py`. O projeto reúne **33 exercícios** em quatro categorias. Para iniciar, execute o arquivo Python, escolha uma categoria pelo número e depois selecione um exercício. Digite `0` para voltar ao menu anterior.

## 1. Fundamentos e matemática

| Exercício | O que pratica |
|---|---|
| Ímpar ou par | Resto da divisão (`%`) e condicionais. |
| Positivo, negativo ou zero | Comparações e `if/elif/else`. |
| Maior de três números | Entrada de dados, listas e `max()`. |
| Média e situação do aluno | Repetição, listas, média e classificação. |
| Conversor de temperatura | Fórmulas e conversão entre Celsius, Fahrenheit e Kelvin. |
| Calculadora básica | Operações aritméticas e validação de divisão por zero. |
| Calculadora de desconto | Porcentagens e cálculos com dinheiro. |
| Contagem regressiva | Laço `for` e intervalos com `range()`. |
| Tabuada | Laços e multiplicação. |
| Fatorial | Laços e a biblioteca `math`. |
| Sequência de Fibonacci | Atualização de variáveis em um laço. |
| Teste de número primo | Divisibilidade, laços e lógica booleana. |

## 2. Textos, listas e jogos

| Exercício | O que pratica |
|---|---|
| Jogo de adivinhação | Números aleatórios, tentativas e dicas. |
| Pedra, papel e tesoura | Escolhas aleatórias e regras de um jogo. |
| Quiz de Python | Listas, respostas, pontuação e embaralhamento. |
| Estatísticas de uma lista | Soma, média, mediana, mínimo e máximo. |
| Remover itens duplicados | Listas, conjuntos e preservação da ordem. |
| Verificador de palíndromo | Manipulação de texto e comparação invertida. |
| Analisador de texto | Caracteres, palavras e frequência. |
| Gerador de senha | Aleatoriedade e conjuntos de caracteres. |
| Cifra de César | Texto, códigos de caracteres e deslocamento alfabético. |

## 3. Pequenos sistemas e arquivos

| Exercício | O que pratica |
|---|---|
| Lista de tarefas | Listas de dicionários, adicionar, listar e remover tarefas. |
| Agenda de contatos | Dicionários, busca e edição de registros. |
| Controle de despesas | Registros, categorias e somatórios. |
| Bloco de notas em arquivo | Leitura e gravação de um arquivo de texto. |
| Salvar e ler dados JSON | Conversão de dados Python para JSON e persistência em arquivo. |

Os dados da lista de tarefas, agenda e despesas ficam na memória enquanto o programa está aberto. O bloco de notas cria `minhas_anotacoes.txt`, e o exercício JSON cria `dados_exercicio.json`, ambos junto ao programa.

## 4. Algoritmos e desafios avançados

| Exercício | O que pratica |
|---|---|
| Busca binária | Busca eficiente em uma lista ordenada e contagem de comparações. |
| Algoritmos de ordenação | Bubble sort, insertion sort e comparação com `sorted()`. |
| Recursão | Uma função que chama a si mesma e caso-base. |
| MDC e MMC | Máximo divisor comum e mínimo múltiplo comum. |
| Conversor de bases numéricas | Representação de números em binário, octal e hexadecimal. |
| Soma e multiplicação de matrizes | Listas aninhadas e operações matriciais. O produto demonstrado é `A × Bᵀ`. |
| Analisador didático de senha | Verificação de critérios de composição de senha. |

## Sugestão de ordem de estudo

1. Comece pelos exercícios de fundamentos, especialmente ímpar ou par, calculadora, tabuada e média.
2. Depois pratique listas e textos com estatísticas, palíndromo e analisador de texto.
3. Avance para os pequenos sistemas para trabalhar com listas, dicionários e arquivos.
4. Termine com busca binária, ordenação, recursão e matrizes.

Tente resolver cada exercício primeiro por conta própria. Depois, compare sua lógica com o código e experimente alterar as regras ou acrescentar funcionalidades.
